# 产品展示图

三张主图均为 3200 × 1800：overview.png（五布局总览）、circuit.png（Circuit 双排版）、lyrics.png（透明歌词）。market-cover.jpg 为适合模组市场的 1600 × 900 JPEG，总览内容相同。

界面由当前组件代码以浏览器渲染导出，图片与文字采用 HTML 排版，保留可编辑的 overview.html、circuit.html、lyrics.html。界面绘制、专辑图比例和文字均未交给绘图模型重画。

风格参考用户提供的「时钟 · FPS · 性能」市场封面：明确的标题层次、完整展示的小组件、干净背景与少量功能说明。本项目采用浅暖底色、深蓝文字与深色歌词专题，形成同一套视觉关系。
