# 自适应卡片设计约束

现行版本：1.15.1。组件按容器与安全空间、内容网格、图像与文字控件组织。

## 信息与对齐

封面 → 专辑名与发行时间 → 歌手 → 歌名 → 当前歌词 → 当前译文 → 下一句 → 时间与辅助控件。
普通卡片使用 Inter，提供 Baskerville 展示字体；纯歌词保留 HotLyric 风格。
每个组件使用标题、内容、辅助三类角色，字重限于 400 / 500 / 600。较大普通卡片使用 32px 标题与 16px 辅助文字，歌词字号仍按用户设置。

专辑、日期、歌手、歌词共享左边线，歌手独立一行。横向排布的主信息与封面顶边对齐，控制区贴齐下侧安全空间。呼吸空间留在信息与控件之间，不将整组内容垂直居中，也不将控件全部堆到顶部。

## 网格与图像

- 基础间距 8px，分组使用 16 / 24px。普通外圆角 24px，纯歌词 10px。
- 普通安全边距：实际宽度 < 360px 或高度 < 248px 用 12px；宽度 < 560px 或竖向重排用 16px；其余 24px。
- 海报按边框内侧与实际安全空间计算，包含小数像素；其他横向卡片的封面宽度对齐到 8px。
- 图片始终使用 object-fit: cover，保持原始比例；极端卡片比例允许裁切，不将图片挤压或拉长。动画只使用统一缩放系数与平移，图像与圆角裁剪框分别负责绘制。
- 主图、主信息、歌词按实际高度预算。没有歌词时不保留占位区域；辅助信息先退让，主信息与封面优先。
- 外阴影限制在窗口 8px 安全范围；退场副本无背景、阴影或模糊，按当前卡片尺寸与圆角裁剪。

## 布局与尺寸

| 布局 | 最小窗口 | 小巧 / 推荐 / 宽裕 |
| --- | --- | --- |
| 海报 | 240 × 200 | 288 × 352 / 320 × 384 / 352 × 432 |
| 胶囊 | 300 × 112 | 320 × 128 / 384 × 160 / 480 × 208 |
| 全功能 | 360 × 240 | 480 × 256 / 528 × 272 / 608 × 320 |
| 纯歌词 | 360 × 100 | 400 × 144 / 512 × 160 / 640 × 208 |
| Circuit | 208 × 336 | 208 × 336 / 304 × 488 / 368 × 592 |

推荐只用于未保存过的布局。更新不会覆盖已有尺寸；设置可主动恢复推荐。

- 海报普通竖版使用完整内容宽度，封面与信息顺序排列；较高窗口增加歌词底栏。极矮海报把主信息放在封面底部渐变区域。
- 海报横向进入阈值：实际宽度 ≥ 368px 且宽高比 ≥ 1.28；退出阈值为宽度 < 352px 或宽高比 < 1.20。左侧主图，右侧上方信息、下方歌词。
- 胶囊与全功能横向采用左主图、右信息与控制区。胶囊实际高度 < 136px 时收起控件，封面仍支持播放。
- 胶囊与全功能在实际高度 ≥ 336px、宽高比 ≤ 1.06 时上下重排；高度 < 312px 或宽高比 > 1.14 后恢复横排。
- 较窄或较矮全功能卡片将进度和三枚主控键放在同一行，隐藏辅助操作与时间标签。
- 纯歌词保持已有外观，极小卡片优先保留当前句及已有译文，悬停也不会强行显示放不下的下一句。

尺寸与字体密度具有 8px 升级余量。布局只在尺寸、字体、内容几何或设置改变时测量，不随播放帧重新计算。

## 沉浸、动效与交互

默认沉浸淡出控件与时间，保留布局与窗口尺寸。隐藏控件不进入键盘焦点。
“未播放时自动隐藏”独立于沉浸与播报：窗口层监听明确的 paused/stopped 状态，950ms 缓冲加 180ms 淡出后 hide，playing 时 showInactive；缺失或缓冲状态不触发隐藏。手动显示意图优先，设置/菜单/指针/排版编辑用独立保持项暂缓隐藏。隐藏窗口继续接收增量状态，恢复时补全快照，不改动窗口尺寸。
旧 autoShrink 一次迁移到 autoHideWhenPaused，schemaVersion 9；旧缩窗有正常尺寸档案时恢复该尺寸。沉浸与播报不再修改原生窗口高度。
统一沉浸参与判定在 Circuit 分支前执行；Tab 在焦点导航前同步恢复控件。切歌播报由原生窗口层负责：收到新歌曲的 playing 状态时恢复整个小组件和原有控件，显示 5000ms，再用 180ms 整体淡出后 hide；下一首 showInactive，不抢焦点、不改尺寸。播放进度和同首元数据更新不重启倒计时，快速连续切歌从最后一次重新计时；隐藏时仍更新歌曲数据，恢复时补全最新快照。
播报期间不增加文字面板、不替换原内容、不改变信息显示项或 Circuit 字号。renderer 只接收 widget-announcement 布尔状态，在沉浸判定中暂时恢复现有控件；贴边抽屉保持展开。设置、菜单、指针手势和排版编辑各有保持项，操作期间不 hide；手动隐藏优先，手动重开可持续到下次切歌。关闭播报恢复窗口，暂停隐藏仍按其独立设置执行。
鼠标、键盘聚焦、菜单、拖动进度或切歌播报恢复交互。纯歌词保留单行 / 双行与三种文字对齐。

封面位移与等比缩放使用 240ms 的 cubic-bezier(0.2, 0, 0, 1)，尺寸与圆角使用同一时间与曲线。原生窗口过渡期间继续平滑调整封面尺寸；直接拖动时取消补间。动画可被新操作中断，点击与状态即时生效。系统要求减少动态效果时关闭补间。

封面单击播放，双击打开独立设置，支持 Tab、Enter 和空格。右键菜单支持方向键、Home / End 与 Esc。
歌词窗口移动与边缘拉伸均捕获当前指针，松开、取消、捕获丢失、无按键移动或失焦均结束。窗口形态与设置操作先结束旧手势，再修改状态，防止旧手势继续改动新布局。

## 偏好设置与歌词渲染

Circuit 海报独立于普通圆角卡片：没有窗口外边距、背景渐变、边框、阴影或角标；上方原封面占完整方形，使用 object-fit: contain 保留完整比例，下方为白色排版区。默认左右边线为宽度的 8.5%，底边约 6.5%。只使用 Inter，字重 500/600，以及标签、信息、大标题三种字号角色。

默认自动策略下，顶部排版的小歌名与信息之间保留至少 6px。歌手与专辑使用参考图正文比例，专辑最多两行；先收起歌手，再收起专辑，日期最后保留。窄于 256px 时收起歌手，窄于 240px 时只保留日期，实际高度不足时提前退化；信息重新出现预留 8px 余量。歌手、专辑、日期均尊重各自显示开关，缺失内容直接省略；歌曲时长默认关闭，启用后展示整首曲目长度，不跟随播放进度刷新。

全部保留与自由选择策略不按窄屏阈值删除已勾选字段；长歌手、专辑等元信息使用一行截断，给日期和歌名保留空间。显示项对三种策略通用，歌名始终保留。设置提供小歌名 10–28px、大歌名 24–120px、信息 10–32px 的字号范围，每个角色可单独恢复自适应；保存值为 0 表示自适应，正值是期望上限。实际字号仍受当前文字区可用高度与行数限制，极小卡片收紧字号，避免手动字号导致裁切。

小歌名与大歌名分别保存信息策略及四项显示开关，存于 information.top / information.bottom。旧平铺设置仅在迁移时复制到两套配置，之后独立修改。设置按当前排版显示对应名称；位置切换与信息更新带显式排版标识，并分别保留待确认项，避免快速切换时串写另一套。切换时退出的字段以短暂副本淡出，共用歌名与日期继续沿原轨迹移动。

自适应大歌名先预留日期行高与至少 6px 间隔，再拟合最多两行；默认目标字号为宽度的 30%，极长文本保留可读字号后两行截断，完整名称保留在 aria-label。中文、日文、韩文行高 1.08，其他文字为 1；按真实行盒高度测量。日期是两种排版共用的同一个元素，默认从左下信息组移动到歌名字块右上方；辅助信息是否保留由策略、显示项与可用空间共同决定。

歌名按钮按字体、字重及实际文字自然宽度测量，短标题不占满整行；超出可用宽度时才受内容宽度限制。小歌名宽度包含标记与间隔，大歌名按自身文字收紧，默认日期锚定其实际右上方。拖动边界使用当前文字框的真实尺寸，避免不可见的整行空白阻挡靠右定位。

小歌名标记边长使用实际拟合字号的 1.25 倍，间隔为字号的 0.28 倍，绘制与自然宽度测量共用同一几何。小歌名行高与标记高度一致；转到大歌名时恢复对应文字行高，标记宽高同步缩至零，保持方形并清除布局占位。手动字号和空间不足时的拟合字号均遵循同一规则。

小歌名的标记使用 `float: left`、`shape-outside: circle(50%)` 与 `shape-margin`，歌名 span 保持 inline，共享按钮内部的普通排版上下文；按钮自身 block/overflow:hidden 负责包含浮动及单行截断。大歌名标记宽度、间距归零，使用独立的两行截断。Shapes 参与浮动区域的行内绕排，按钮盒模型仍由文字测量决定，符合 [CSS Shapes 的浮动与盒模型规则](https://drafts.csswg.org/css-shapes-1/)。

非编辑状态下，上下拖动歌名与键盘切换使用可中断的 360ms 补间，直接拖动跟随指针，松开后吸附。设置提供小歌名 / 大歌名切换按钮；字号、密度、字段与位置变化可使用排版过渡，关闭动画或系统要求减少动态效果时直接切换。Circuit 保存自己的尺寸与两套排版，切回原主题恢复原布局，自动缩窗不会改变此主题比例。

Circuit 切歌的专辑、日期与时长可能分批到达。动画开启时按 96ms 静默窗口合并内容，连续更新最长等待 240ms；相同内容的播放进度快照不重新计时，只保留最新内容。手动排版或标题手势开始前提交并同步测量；正在拖动或切换大小歌名时等待手势结束。非 Circuit、关闭动效、减少动态效果以及设置操作直接提交；封面继续独立加载。较晚到达的元数据仍可再次改变目标字号，自定义值继续作为可用空间内的期望上限。

重排快照记录当前 transform 对应的视觉字号与透明度，下一段过渡从正在显示的像素继续，避免使用 CSS 最终字号重新缩放。测量时刷新动画快照，只保留旧文字与出场信息；相同尺寸、内容与排版配置的测量不重启动画，字体加载完成仍触发必要的测量。切歌保持原有密度重置规则，避免继承上一首歌的信息退化状态。

自由编辑仅在当前窗口开启，不持久化。歌名、歌手、专辑、日期及已启用的歌曲时长可二维拖动，开始时停止旧布局补间，按文字实际矩形限制在白色区域内；拖动期间保持预览，松开后提交，失焦、取消、指针捕获丢失或 Esc 撤销本次预览。Enter 或完成按钮提交当前移动并退出；未拖动时 Esc 退出编辑。编辑字段支持 Tab 导航，方向键每次移动 1px，Shift+方向键移动 8px，Alt+左右方向键直接贴齐左右边缘，并阻止全局播放快捷键误触。

指针拖动距左右边缘 8px 内自动吸附；保存 `align` 锚点后，文字长度或窗口宽度变化继续保持所选左右对齐。普通键盘微调只按实际文字左沿计算位移，不应用 8px 吸附，保证从贴边位置也能逐像素移开。

小歌名与大歌名分别保存各字段的位置，坐标使用文字区宽高的归一化比例。`x` 对应 `align` 指定的左、右或中心锚点，`y` 对应上沿；旧数据没有 `align` 时按 left 解释，保持原有左上比例位置。改变窗口尺寸后沿用比例位置并重新限制边界，字号与字段内容变化仍需测量实际几何。退出编辑恢复常规焦点顺序与窗口拖动规则，并收起编辑提示及完成按钮；恢复默认同时清除两套自定义位置并还原显示项、字号、字重和动画偏好。

偏好设置参考 [Apple 设置指南](https://developer.apple.com/design/human-interface-guidelines/settings) 的分类、稳定导航与分组原则。窗口固定浅灰 #f5f5f7、白色分组、深色文字与蓝色选择标记，独立于音乐主题。默认 560 × 640，最小 400 × 440；标题、分类和底部提示固定，内容单独滚动。外观、交互、歌词页面分别保留滚动位置，重新打开恢复上次分类。

选择器锚定当前控件并避让窗口边缘，列表通过独立层避开分组裁剪；展开 240ms、退出 120ms，选项轻微错峰，快速操作会中断旧动画。键盘焦点留在组合框，方向键选项导航，Enter 确认；第一下 Esc 收起列表，之后关闭窗口。系统要求减少动态效果时直接切换。

纯歌词样式独立保存六项颜色、背景不透明度、描边宽度、字重与渲染方式。设置预览不改变播放器布局；较窄窗口把预览放在颜色列表上方。普通卡片保持原有样式。

暖白卡片使用米白 #f6f1e7、暖棕文字 #342d23 与棕色控件 #8c6335，分组、边线与阴影使用同一暖色倾向；主题色样与实际底色保持一致。极简浅色保持 #ffffff。独立设置窗口继续使用固定浅灰 #f5f5f7，纯歌词与 Circuit 保持各自样式。

默认灰度渲染在透明 Canvas 字形层中使用屏幕 DPR 作为像素密度，缓存基础与高亮填充和描边；逐词进度仅裁切合成缓存层，替换 alpha 覆盖避免重复描画造成字边变粗。可访问歌词文本保留在 DOM，Canvas 不可用时回退。去除歌词模糊投影与常驻 will-change；静止时无 transform，长句跟随使用对齐物理像素的二维位移。字体、显示缩放及设置变化才重建几何与字形层。

歌词顶部控制栏由独立的 `showLyricToolbar` 偏好控制，默认显示。关闭时使用 hidden 和 inert 移除布局占位与焦点，歌词主体取消上下不对称的内边距；恢复显示后仍遵循沉浸模式。隐藏状态不影响右键菜单、播放快捷键和拖动。

歌词背景不透明度为零时，边框变量同步归零，移除窗口阴影、外轮廓与角落缩放标记；透明边框保留原有几何，缩放手柄只隐藏装饰而保留命中区域。清除阴影的规则覆盖切歌播报动画，悬停也不重新显示边框。恢复非零值时使用已保存的边框颜色与常规阴影，独立设置预览共用相同样式变量。

歌词窗口移动通过 `move` 消息仅传递位置，主进程使用 setPosition，绝不从 renderer 的 innerWidth/innerHeight 回写原生尺寸；页面缩放下两者可能不相等。移动与边缘缩放使用不同状态，按住时暂停自动缩窗，结束时恢复一次判断；中断原生尺寸动画后清理旧目标缓存。移动最终保存位置并应用 18px 磁吸，保留正常高度档案。边缘缩放与沉浸缩放读取原生尺寸快照。

## 模块职责

歌词翻译使用宿主 `FoliumLine.translation`，缺失时从 `alternateTexts` 的 translation 角色选择中文译文；不将 romanization 当作翻译，不生成或请求外部翻译。歌词加载事件与快照补齐共用同一提取逻辑，切歌清理旧译文，翻译晚于原句到达时仍立即更新。独立 `showLyricTranslation` 开关默认开启并持久化。

排版采用原文、译文、下一句三层层次。译文单行截断，完整文字保留在 title 和 DOM 中；原文与译文间距为 4px，纯歌词译文字号为原文的 64%，下一句更淡。译文与原文共用同步时间、对齐和灰度 Canvas 渲染；无译文不产生空行。纯歌词按整首歌是否具有翻译预留字号，避免不同歌词行之间反复改变原文字号；最小窗口优先保留原文和译文。普通卡片在原有封面和专辑优先级内分配翻译空间，先收起下一句和时间，再收起译文。Circuit 不增加歌词区域。
