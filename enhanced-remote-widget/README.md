# Folia 增强版悬浮小组件

适用于 Folia 桌面版的独立音乐小窗，当前版本 **1.15.2**，兼容范围为 **Folia 0.7.9**。本版为发布前修复包，真实宿主的多屏、DPI、透明窗口与长期运行验收尚未完成。

项目源码采用 [MIT 许可证](LICENSE)。随附的 Inter 字体采用 SIL Open Font License 1.1，见 [字体许可证](INTER-LICENSE.txt)。市场收录由 Folium 维护者审查和签名后完成。

## 界面与功能

| 布局 | 默认尺寸 | 展示内容 |
| --- | --- | --- |
| 海报款（首次启动默认） | 320 × 384 | 封面与专辑信息贴合排列；较高窗口增加歌词，横向拉宽后左右分栏 |
| 紧凑胶囊 | 384 × 160 | 左侧封面，右侧专辑、日期、歌手与播放控制；320 × 128 的小巧档仅保留核心内容 |
| 全功能 | 528 × 272 | 左侧封面，右侧信息与完整播放控制；窄高窗口自动上下排列 |
| 纯歌词 | 512 × 160 | 参考 HotLyric 的桌面歌词：轻量控制栏、当前歌词与较小的下一句、白字橙色逐词高亮 |
| Circuit 海报 | 304 × 488 | 无边框原封面与黑白文字区；小歌名、大歌名两套排版，各文字块可独立调整 |

- 六种主题：暖白纸质、石墨深色、封面自适应、极简浅色、悬浮透明、Circuit 封面海报。
- 暖白使用米白底色与暖棕文字、控件；极简浅色保持纯白。设置窗口固定浅灰外观。
- Circuit 小歌名的图标与间距跟随实际字号，手动调整或空间拟合时同步变化；切换到大歌名时保持正方形缩小并淡出。
- Circuit 切歌合并短时间内连续补齐的信息，减少字号先放大再缩小；后续信息到达时从当前显示的字号与位置继续过渡，保留自定义排版。
- 播放/暂停、上一曲、下一曲、喜爱、打乱队列；部分功能取决于歌曲来源和宿主支持。
- 拖动进度条跳转；滚轮可选择音量（每次 5%）、歌曲进度（每次 5 秒）或上一首／下一首，默认仍为进度。
- 窗口置顶、位置锁定、18 像素屏幕边缘磁吸、位置与尺寸记忆。
- 独立设置窗口分为外观、交互、歌词三页，固定浅灰背景与白色分组，记住上次打开的页面。
- Circuit 在外观页提供自由排版、显示项、三种字号、两档字重与动画开关；两种歌名排版分别保存文字位置。
- 纯歌词支持灰度抗锯齿与系统渲染、三档字重、六项颜色自定义、背景不透明度与描边宽度；调整时显示实时预览。
- 在“歌词 → 歌词显示”中开启或关闭“歌词翻译”（默认开启）。使用宿主提供的当前句译文；纯歌词、海报、全功能与胶囊中的歌词区域共用此设置。原文下方显示较小的译文，没有译文或与原文重复时自动收起；空间不足时先隐藏下一句，再收起译文。纯歌词最小窗口会适度拟合字号，优先保留原文与译文。Circuit 保持原有封面与文字设计。
- 在“歌词 → 歌词显示”中可关闭“顶部控制栏”，保留完整歌词空间；该选择会保存，右键菜单和快捷键仍可使用。
- 歌词背景不透明度设为 0% 时隐藏背景、边框、阴影和角落缩放标记，恢复大于 0% 后还原；边缘缩放仍可操作。
- 五种布局独立记住窗口尺寸和歌词字号；切换布局时沿用当前屏幕位置的边缘或中心锚点。纯歌词布局支持左、中、右对齐与单行／双行。
- 歌词同步可提前或延后 5 秒，滑块每步 50ms，按钮每步 100ms；仅影响歌词显示，不改变音频或进度。
- 同步偏移按歌曲来源和 ID 保存，最多保留最近 256 首；没有 ID 时使用歌名、歌手和专辑区分。
- 沉浸模式默认只淡出进度、播放按键和时间，保留封面、主信息的位置和窗口尺寸；鼠标移入、键盘聚焦或拖动进度时恢复，移出后延迟约 450ms 淡出。
- 未播放时自动隐藏：暂停或停止 950ms 后淡出并隐藏整个窗口，继续播放自动显示且不抢焦点；所有主题与布局统一适用。设置、菜单、拖动和排版编辑期间暂缓隐藏。手动隐藏仍需手动重新打开；未播放时手动打开可持续操作，直到播放状态再次改变。
- 切歌播报是整个小组件的临时展示：切歌时恢复原有封面、信息、歌词与可用控件，显示 5 秒后整个窗口淡出隐藏，下次切歌重新出现。保持当前主题、布局、字号与尺寸，使用现有信息显示规则；贴边抽屉在播报时展开。设置、菜单、拖动和排版编辑期间暂缓隐藏，结束后继续收起。手动隐藏优先，手动重新打开后可持续操作到下次切歌；关闭播报恢复常驻，仍遵循“未播放时自动隐藏”的独立选项。
- 普通卡片单击封面可播放／暂停，双击直接打开偏好设置；封面支持 Tab 聚焦及 Enter / 空格播放。

专辑、封面和发行日期优先使用宿主数据；缺失时尝试公开音乐接口。未找到匹配歌曲时显示“未知”，网络请求在后台进行。

## 快捷键与交互

| 按键 / 操作 | 作用 |
| --- | --- |
| 鼠标右键（任意位置） | 在点击位置展开上下文菜单 |
| 菜单键或 Shift+F10 | 用键盘打开上下文菜单；方向键、Home/End 导航，Esc 关闭 |
| 触屏或触控笔长按 | 打开上下文菜单；移动手势会取消长按 |
| 双击封面 | 打开或聚焦独立的「偏好设置」窗口 |
| S 或 , | 打开或聚焦独立的「偏好设置」窗口 |
| 空格 | 播放 / 暂停 |
| L | 循环切换五种布局 |
| I | 切换沉浸模式 |
| T | 循环切换主题 |
| F5 或 Ctrl+R | 刷新 / 热重载小组件界面 |
| Esc | 在小组件中关闭右键菜单；在设置窗口中关闭设置 |
| Circuit 非编辑状态下，上下拖动歌名 | 切换小歌名与底部大歌名；设置中的“小歌名 / 大歌名”按钮也可切换 |
| Circuit 编辑状态下，拖动文字 | 独立移动歌名、歌手、专辑、日期与已开启的歌曲时长 |
| Circuit 编辑状态下，方向键 / Shift+方向键 | 移动当前聚焦的文字 1px / 8px；Tab 切换文字焦点 |
| Circuit 编辑状态下，Alt+左右方向键 | 将当前文字贴齐左边缘 / 右边缘 |
| Circuit 编辑状态下，Enter 或“完成” | 保存当前移动并退出编辑 |
| Circuit 编辑状态下，Esc | 拖动时取消本次移动；未拖动时退出编辑 |

常规卡片的设置、锁定、置顶、主题与布局操作集中在右键菜单；纯歌词布局另有桌面歌词顶栏，可直接切歌、播放、锁定位置、打开设置和隐藏窗口。菜单按点击位置展开，自动避让窗口边缘；在 Windows 拖拽区域，原生右键消息负责补齐 DOM 收不到的事件。偏好设置使用可独立移动、缩放的原生窗口，设置项可滚动；重复打开会聚焦已有窗口，Esc、完成按钮或窗口关闭按钮可退出。

纯歌词模式：打开小窗偏好设置，选择“纯歌词”。首次切入使用 512 × 160 和 28px 字号，之后恢复该布局上次使用的设置。默认显示 HotLyric 风格顶栏与两行歌词；沉浸模式闲置时收起顶栏和第二行，悬停后恢复。小窗口会自动缩小字号并隐藏第二行以避免裁切。

关闭“顶部控制栏”后，悬停也不会显示顶栏；歌词在剩余空间中居中。左键按住歌词区域可移动窗口，移动只改变位置；在边缘或角落拖动才调整尺寸。拖动期间暂停自动缩窗，松开后恢复判断；位置锁定后歌词区域不可拖动。

Circuit 自由排版：在偏好设置的外观页选择 Circuit，打开“Circuit 排版 → 编辑排版”，即可在卡片中移动文字。“小歌名”和“大歌名”各保存一套位置，位置随窗口尺寸按比例适配；退出或重开窗口不会自动进入编辑。字号可使用自适应，也可设置小歌名 10–28px、大歌名 24–120px、信息文字 10–32px，并选择 500 或 600 字重。手动字号是期望上限，极小窗口仍会按可用空间收紧，避免文字裁切。

歌名按实际文字宽度定位，短歌名的可拖动范围随文字收紧。拖动到左右边缘 8px 内会自动贴边，并保存对应的对齐方式；之后缩放窗口或改变歌名长度仍保持贴边。Alt+左右方向键可直接贴齐边缘，普通方向键保持每次 1px 微调，不受拖动吸附范围影响。没有对齐信息的旧位置继续按原有左上坐标读取。

信息策略可选自动精简、全部保留或自由选择。歌手、专辑、发行时间、歌曲时长均可单独开关，歌名始终显示；自动精简会按空间收起选中的辅助信息，全部保留与自由选择保留勾选字段，放不下的长元信息采用一行截断。歌曲时长显示整首曲目长度，不随播放进度变化。“恢复默认”同时还原字号、显示项与两套文字位置；“排版过渡”可关闭，系统开启减少动态效果时也直接切换。

普通卡片采用 8px 网格与 24px 外圆角；小卡片使用 12px 安全边距，常规卡片使用 16px，宽大卡片使用 24px，纯歌词保留独立外观。展示顺序为封面 → 专辑名与发行时间 → 歌手 → 歌名和歌词。信息与封面顶边对齐，控件贴齐下侧安全空间，中间保留呼吸区域。极矮胶囊收起控件后仍可通过封面、空格或右键菜单播放。已保存的窗口尺寸不会随推荐值更新而重置。详细约束见 [DESIGN.md](DESIGN.md)。

## 安装与更新

本版把此前的任意宿主版本声明收紧为 0.7.9，避免内部音量接口变更后仍被误判兼容。升级其他 Folia 版本前，需要重新核对内部音量能力并更新兼容声明。

更新新增 `ui.stage` 权限：注册不显示内容、不接收输入的播放页图层，读取公开歌词时钟，使歌词跟随宿主歌词偏移和仅歌词来源；不替换宿主歌词界面。宿主尚未挂载该图层时回退到音频时间。重载后请完成宿主对新文件和权限的授权确认。

| 权限 | 用途 |
| --- | --- |
| playback.control | 播放、暂停、切歌、进度和喜爱操作 |
| runtime.playback | 主进程补齐当前歌曲与歌词快照 |
| filesystem.data | 保存窗口位置与布局尺寸 |
| net.fetch | 缺少歌曲信息时查询网易云或 iTunes；查询会包含歌曲 ID，或歌名与歌手 |
| ui.stage | 从无视觉内容的播放页图层读取公开歌词时钟 |

设置内容保存在组件本地存储中；网络补全只采用来源与歌曲身份匹配的结果，不能确认时保留缺失信息。

### 拖拽安装

1. 在 Folia 的“设置 → 实验室 → 模组系统”中开启模组支持。
2. 用命令面板（Ctrl / Cmd + K）打开模组管理面板。
3. 将 enhanced-remote-widget.zip 拖入模组管理面板安装。
4. 启用“增强版悬浮小组件”，完成宿主的原生授权确认。

### 手动安装

1. 停用已经安装的同名模组。
2. 将模组文件夹命名为 enhanced-remote-widget，再复制到 %APPDATA%\Folia\mods；更新时替换该模组的代码文件。
3. 在模组面板中重载并重新启用，确认代码更新后的原生授权提示。

启用后会自动显示小窗，也可通过播放条的小窗按钮或命令面板切换显示。

## 1.15.2 更新

- 修复滚轮音量指令被主进程过滤；拒绝无效增量并限制单次幅度。保留 Folia 0.7.9 音量状态与持久化，内部接口不可用时提示。
- 刷新、渲染进程退出和重新初始化时释放旧页面的编辑、菜单与鼠标占用；设置窗口打开时仍保护组件，不自动隐藏。
- 修复贴边探头的兄弟元素选择器、左右位置、方向指示和主题色；完全离开窗口后恢复收起，操作期间保持展开，结束后恢复判断。
- 贴边保留整个小组件的淡入淡出；透明歌词与 Circuit 继续遵循自身边框和阴影规则。
- 歌词与进度使用独立时钟；无可见歌词、进度或时间的布局停止持续动画循环。歌词退出动画保留 Canvas 位图，复制失败时回退文字。
- 两个窗口使用隔离的预加载通信接口，关闭页面 Node 集成、恢复 webSecurity 并开启沙箱；限制脚本来源、页面导航与新窗口。
- 右键菜单临时扩展窗口时遵循当前显示器工作区，支持负坐标显示器。
- 预览图扩展名改为与实际 JPEG 格式一致；正式市场预览仍需补充本版真实截图。

## 1.13.0 更新

- 新增 Circuit 封面海报：清晰显示原始封面，去除外边距、渐变背景、边框、阴影与装饰角标；非方形封面保持完整比例。
- 默认小歌名位于文字区上方，下方依次显示歌手、专辑、发行时间。自动策略按实际空间逐步收起歌手、专辑，小巧档最终保留选中的日期；缺失字段直接省略。
- 非编辑状态下，上下拖动歌名切换两种排版，向下变成底部大标题，日期平滑移动到歌名右上方。支持方向键、Home/End、Enter/空格，也可在设置中切换设计。
- 新增自由排版：编辑时歌名、歌手、专辑、日期及可选歌曲时长可分别拖动；方向键移动 1px，Shift+方向键移动 8px，Enter 或完成按钮结束编辑，Esc 取消当前拖动或退出编辑。
- 小歌名与大歌名的文字位置分别保存，使用比例坐标适应不同尺寸；编辑开关仅在当前窗口生效，不持久化。
- 两套排版的信息显示也分别保存：先选择小歌名或大歌名，再调整该排版的信息策略和歌手、专辑、日期、时长开关；可以小歌名显示全部、大歌名只留日期。旧版共同设置会迁移到两套，之后互不影响。
- 歌名框按实际文字宽度收紧；拖动距左右边缘 8px 内吸附，保存左右对齐锚点，Alt+左右方向键直接贴边，普通方向键仍按 1px 自由微调。旧比例位置兼容读取。
- 小歌名的标记采用 CSS Shapes 浮动绕排，文字与标记共享行内排版；大歌名隐藏标记并保持两行截断。默认日期跟随歌名实际右上方。
- 设置可选择自动精简、全部保留或自由选择，独立开关显示项，调整三种字号及 500/600 字重。字号作为期望上限，极小卡片按可用空间适配；强制保留时，较长的元信息一行截断。
- 字号按实际文字拟合，中文使用适合的行高，大标题最多两行；极长标题保留可读字号并截断，完整名称仍提供给辅助技术。排版过渡可关闭，并尊重系统减少动态效果设置。
- Circuit 独立保存尺寸，首次推荐 304 × 488，小巧 208 × 336，宽裕 368 × 592；边缘缩放与较矮屏幕推荐值保持海报比例。切回普通主题时恢复原来的布局。
- Circuit 保持封面与文字，播放、设置等操作通过右键菜单和快捷键使用，沉浸自动缩窗不会挤压此主题。

## 1.12.0 更新

- 重构独立偏好设置：固定浅色背景、三页分类、紧凑分组，默认 560 × 640，最小 400 × 440。切换小组件主题不会改变设置窗口颜色。
- 滚轮操作使用带选中标记、方向说明和可中断动效的选择器；支持方向键、Enter、Tab 与分层 Esc。触控板小幅滚动累积后触发，连续切歌限频。
- 纯歌词默认使用透明高 DPI Canvas 字形，按屏幕像素比例绘制；去除固定模糊投影，静止文字不再永久合成位移，长句位移对齐屏幕像素。
- 新增窗口边框、背景、歌词、卡拉 OK、歌词描边、卡拉 OK 描边六项颜色，以及不透明度、描边宽度和字重。经典橙白、清爽浅色可快速恢复；更改即时保存。
- Canvas 分别绘制基础与高亮描边，保留可访问的 DOM 歌词；不可用时回退。系统渲染沿用浏览器文字，高亮描边在整词完成时切换。
- 音量复用 Folia 自身的音频状态与持久化，避免小窗与主播放器音量脱节；当前核对版本为 Folia 0.7.9，其他宿主未提供接口时会给出提示。

抗锯齿实现参考 [高 DPI Canvas](https://developer.mozilla.org/en-US/docs/Web/API/Window/devicePixelRatio)。Windows 上的 CSS font-smoothing 不能强制灰度抗锯齿，因此清晰模式使用透明字形画布；字形细节仍取决于宿主 Chromium、系统字体与显示缩放。

## 开发说明

- index.cjs：Electron 主进程窗口、存储和消息转发。
- client.mjs：Folium 客户端状态、歌词、歌曲信息和播放控制。
- widget.html / widget.css：小窗结构与主题、布局样式。
- widget.mjs：按窗口类型加载播放器或设置界面。
- widget-player.mjs：播放器交互、窗口状态与消息连接。
- widget-settings-window.mjs：独立设置窗口的控件和状态显示。
- widget-context-menu.mjs：动态右键菜单的动效、键盘与触控交互。
- widget-state.mjs：共享状态、默认布局、设置迁移与序列化。
- widget-settings.mjs：设置控制、各布局字号与歌曲同步偏移。
- widget-lyrics.mjs：歌词选择、逐词绘制、播放时钟与刷新生命周期。
- widget-ui.mjs：文字／图标形变与封面配色。
- widget-layout.mjs：卡片尺寸观察、自适应主图和横竖布局切换。
- widget-motion.mjs：短淡入淡出、布局位移、无交互退场副本与动画生命周期。
- widget-circuit.mjs / widget-circuit.css：Circuit 原封面、信息密度、文字拟合与两套排版过渡。
- widget-circuit-style.mjs：Circuit 字号、显示项、动画与比例位置的默认值及校验。
- widget-circuit-edit.mjs：文字拖动预览、位置提交、键盘微调与编辑生命周期。
- DESIGN.md：网格、文字角色、主图与控件的共用设计约束。
- InterVariable.woff2 / INTER-LICENSE.txt：本地字体及其开源许可。
- window-layouts.cjs：主进程的窗口位置与尺寸记忆。
- cube-motion.js：保留的旧动画库，当前界面入口不再加载。
- mod.json：模组入口、版本和权限声明。

这是直接由宿主加载的模组，无构建步骤。浏览器预览可用于查看布局和设置；播放控制与原生窗口功能需要在 Folia 内运行。

使用 Folium 的公开事件、RPC、存储和播放快照接口；宿主内部数据仅作为信息补充，读取不可用时降级。导出窗口不启动播放控制和状态轮询。
