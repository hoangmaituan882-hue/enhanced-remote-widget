# Folia 增强版悬浮小组件

Folia 桌面音乐小组件，当前版本 **2.0.0**，适配 Folia 0.7.22 及后续 0.7.x 版本。

支持海报、胶囊、全功能、纯歌词和 Circuit 五种布局，提供自由排版、歌词翻译、逐词高亮、独立设置窗口、可配置滚轮操作、沉浸模式、未播放时隐藏、整窗切歌播报、可关闭的切歌画面过渡与歌词换句过渡。

![五种布局总览：海报、Circuit、全功能、胶囊与歌词](docs/visuals/overview.png)

## 2.0.0 更新说明

本版汇总 1.15.5 以来的改进，重点完善桌面歌词、日常操作与异常恢复。

- **歌词体验**：系统字体、灰度抗锯齿、字重与配色、透明背景、默认开启的译文，以及可关闭的换句和切歌画面过渡；跳进度与后台恢复直接定位，逐词高亮保持同步。
- **状态栏伸缩**：隐藏时不占位，唤起时随卡片高度平滑向上展开，歌词位置与底边稳定，不改写窗口尺寸档案。
- **全区域交互**：文字、封面与空白共用滚轮操作，普通内容单击播放／暂停；拖动仅移动位置，不拖出封面、不累积放大，专用控件与 Circuit 排版继续独立操作。
- **独立右键菜单与静默穿透**：菜单不再撑高组件；点击穿透期间不响应其他输入，仅通过右键菜单关闭，另有宿主恢复命令应急。
- **连接与窗口恢复**：断连冻结内容并禁用播放操作，重连补齐快照；位置、推荐尺寸可独立重置，保留原有设置、歌词偏移和五布局档案。

从 1.x 升级无需重置数据，替换代码后在 Folia 模组面板重载并确认授权。**2.0.0 是小组件版本，仍使用 Folium 1.7 公开接口与 `folium: 1` 清单，兼容 `Folia >=0.7.22 <0.8.0`。**

离线回归共 109 项，组件脚本语法检查共 35 个；真实宿主透明窗口、焦点、穿透、多屏 DPI 与长期运行仍需验收。仓库提交不等于市场上架，新版本需维护者审核与签名。[完整更新记录](enhanced-remote-widget/README.md#200-更新)。

## 自由排版

小歌名与大歌名各保存一套排版。拖动歌名切换重心，独立调整字号、位置与显示信息。

![Circuit 小歌名和大歌名两种排版](docs/visuals/circuit.png)

## 专注歌词

逐词高亮与翻译，支持透明背景、隐藏控制栏，以及字号、颜色与描边调整。「歌词 → 翻译设置 → 显示翻译歌词」默认开启并保存，原文下方跟随显示宿主译文，无译文时自动收起。

![透明背景、歌词翻译与逐词高亮](docs/visuals/lyrics.png)

展示图由当前组件代码实际渲染并排版，使用真实歌曲封面；演示文字与界面设置用于说明功能。[图片与素材来源](docs/visuals/CREDITS.md)。

## 安装

将本仓库的 enhanced-remote-widget 文件夹复制到 Folia 的 mods 目录，在模组管理面板启用并确认权限。Windows 的目录为 %APPDATA%\Folia\mods。

[详细说明与权限用途](enhanced-remote-widget/README.md) · [设计说明](enhanced-remote-widget/DESIGN.md)

## 兼容与验证范围

兼容范围为 `>=0.7.22 <0.8.0`。使用公开的音量、歌曲详情、歌词时钟、存储和生命周期接口，已清除 Folium 2 将移除的旧写法；原有窗口与排版设置继续保留。

当前官方稳定版提供 Folium 1.7，所以清单仍声明 `folium: 1`。Folium 2 正式发布后需核对其实际契约并更新清单主版本。

1.29.0 纯歌词状态栏收起不再占位，唤起时随卡片高度平滑向上展开，歌词区与底边稳定，不改写窗口尺寸档案；累计 109 项离线测试通过。1.28.0 在歌词页顶部新增独立的翻译设置，提供默认开启且可保存的「显示翻译歌词」开关，沿用宿主译文并保留旧的关闭选择。1.27.0 新增默认开启且可保存的歌词换句过渡，原文、译文和下一句轻柔衔接，跳进度及后台恢复直接定位；累计 95 项离线测试通过，真实宿主视觉效果仍需验收。1.26.0 右键菜单改为独立透明浮窗，不再撑高小组件。1.21.0 新增封面、歌曲信息和歌词的切歌画面过渡，支持快速中断、异步内容短暂保留及减少动态效果；1.20.2 修复旧底部按钮残留引用引发的播放状态更新中断，恢复歌词、时间和进度交互，并移除临时诊断输出；1.20.0 改进进度条指针捕获，并在渲染端启动时补拉全量歌词；1.19.0 把歌词字体改为系统字体下拉并修复设置行排版；1.18.0 重做纯歌词控制（单一悬停状态栏、收藏上移、取消关闭按钮、点击穿透、字号随窗口缩放）；1.17.1 修复设置页卡片样式回归；1.17.0 新增可自定义的歌词字体；1.16.0 合并外部 1.15.5 本地修改版并保留 Circuit 右键、纯歌词边缘平移与图片拖放修复。这些改动尚未在真实宿主里核对。1.15.4 的宿主兼容修复与 1.15.5 的展示图此前已通过宿主官方模组检查，无兼容性错误或弃用提醒。市场新版本收录需要 Folium 维护者审核与签名。
